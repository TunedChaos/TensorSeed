Tensorseed HTTP mirror

This host is an HTTP mirror and BitTorrent webseed for the official Tensorseed catalog. It stores exact copies of the files listed in the signed catalog so Tensorseed clients can fetch them over plain HTTP when there are not enough BitTorrent peers. There is no directory listing here: clients find files through the catalog.

You do not need to trust this mirror. Every file is checked against the hashes in the catalog, which is signed with minisign and anchored on the Chia blockchain.

To download a model, use the Tensorseed client:

tensorseed pull openai-community/gpt2

Layout:

/t/<name>@<revision>.torrent     torrent metadata
/t/<name>@<revision>/<file>      webseed file data
