# tensorseed.dev

The Tensorseed website: a SvelteKit app with Tailwind CSS and daisyUI,
sharing the theme and components in `ui/` (`@tensorseed/ui`) with the
explorer and Tensorseed Desktop. `adapter-static` prerenders every route
to its own HTML file, so the site needs no server and works without
JavaScript; once loaded, navigation happens in the page.

```sh
pnpm install --frozen-lockfile
pnpm dev          # http://127.0.0.1:5174
pnpm check        # svelte-check
pnpm build        # build/, ready for Cloudflare Pages
pnpm test:links   # internal links and anchors in build/ (add -- --external for URLs)
```

## Layout

- `src/routes/`: one folder per page (`/download`, `/desktop`, `/serve`,
  `/guides`, `/verify`, `/support`), plus `404/` (prerendered to
  `404.html`, no JavaScript) and `sitemap.xml`.
- `src/routes/guides/[slug]/`: the guides, rendered at build time from
  `docs/*.md`. Links between guides become site routes, other repo links
  go to GitHub, and headings get the same anchors as on GitHub. The list
  is in `src/lib/guides.ts`.
- `src/lib/release.ts`: the release version and every download file name.
  A new release changes `VERSION` only, unless its files change.
- `src/lib/site.ts`: site URL, keys, navigation, and the old `/#anchor`
  links that the home page forwards to the new routes.
- `static/`: favicon, `og.png`, the XCH QR code (regenerated by
  `scripts/generate-xch-qr.py` from `xch-donate-address.txt`),
  `_headers`, `_redirects`, `robots.txt`, and Desktop screenshots.
- `catalog/` and `mirror/`: static trees, copied into `build/` by
  `scripts/assemble.mjs`. `catalog/` is also its own Pages project.

## URLs on Cloudflare Pages

`trailingSlash` is `never`, so `/download` is written as `download.html`.
Pages serves it at `/download` and redirects `/download.html` and
`/download/` there. Any path without a file gets `404.html` with a 404
status; there is no single page app fallback.

`site/deploy.sh` builds this app and deploys `build/` to the `tensorseed`
project.
