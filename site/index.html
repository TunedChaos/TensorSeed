Tensorseed

A signed catalog and a swarm for Hugging Face models.

What it is

Tensorseed is a tool that mirrors Hugging Face models and datasets and verifies them. Bytes move over BitTorrent v2 and hybrid torrents, plus HTTP and S3-compatible mirrors. A signed catalog sits on top, so you can find a revision, check its signature, and fetch the same files from more than one place.

Chia DataLayer is the source of truth for the catalog: every catalog revision is anchored on Chia mainnet first, and the signed file tree served over HTTPS is a cache that clients check against the chain.

Signed catalog

Each revision publishes a signed head, an append-only delta, and periodic snapshots. Clients pin a publisher key, walk a hash chain, and reject rollback, forks, and stale heads. The catalog for this project will be served from catalog.tensorseed.dev.

BitTorrent v2

Model and dataset bytes are published as BitTorrent v2 or hybrid torrents, with HTTP webseeds so a pull still works when the swarm is quiet. Operators can seed what they already verified.

HTTP and S3 mirrors

Named, repeatable provider blocks describe R2, B2, S3, and other HTTP mirrors. A signed mirrors.toml is published with the catalog so clients can discover sources without a chain.

Status

The software is under active development. The signed catalog is live at catalog.tensorseed.dev. The first published model is TunedChaos/ChaosNexus_Tuned_v1-GGUF. Object bytes are mirrored at mirror.tensorseed.dev. See the catalog README for the file layout.

Verify the catalog

Pin this publisher public key (minisign, key id CE1E0E3D543DFFB8) in catalog.publisher_pubkey. Clients reject any catalog file that is not signed by it. 

RWS4/z1UPQ4ezmjrcpKqDYpqyn5h1WUS2oDs1B73Dh91kVzzNIZd03xd

Pin the Chia mainnet DataLayer store that anchors the catalog in chia.catalog_store_id. Clients accept a catalog head only when the chain anchors it. 

3dcd43dced47a32f8e38e8ec77f583d8d1bafe1ab24e381538e50a36034b7a76

Client config:

[catalog]
backend = "file"
name = "tensorseed"
publisher_pubkey = "RWS4/z1UPQ4ezmjrcpKqDYpqyn5h1WUS2oDs1B73Dh91kVzzNIZd03xd"
chain_check = "strict"

[file]
base_url = "https://catalog.tensorseed.dev/"

[chia]
catalog_store_id = "3dcd43dced47a32f8e38e8ec77f583d8d1bafe1ab24e381538e50a36034b7a76"
chain_source = "light"
coin_api_urls = ["https://api.coinset.org"]

Then run tensorseed catalog chain-status, catalog info, list, show, pull, and verify. No Chia software is needed: the client checks the published chain-proof.json against a public Chia full node API.

Verify a release

Release archives ship with SHA256SUMS and SHA256SUMS.minisig, signed by the release key (minisign, key id F5D2D3C4C27D459D). This is a different key from the catalog publisher key above. Do not verify binaries with the catalog key. 

RWSdRX3CxNPS9Vl1JNjDnZ04OmM/3xrfp9vqG5FO8TNpK8Sbg6ENAI4P

Check a download:

minisign -Vm SHA256SUMS -P RWSdRX3CxNPS9Vl1JNjDnZ04OmM/3xrfp9vqG5FO8TNpK8Sbg6ENAI4P
sha256sum -c --ignore-missing SHA256SUMS
