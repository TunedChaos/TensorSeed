Tensorseed catalog

This is the public base URL for the signed static-file catalog (file.base_url in Tensorseed). The catalog is not published yet.

When it is, documents live under one directory per logical catalog name, as specified in docs/SPEC.md sections 6.8 and 6.12: 

<base_url>/<catalog>/head.json
<base_url>/<catalog>/deltas/<revision:010>.json
<base_url>/<catalog>/snapshots/<revision:010>.json
<base_url>/<catalog>/mirrors.toml

Each of those files has a detached .minisig. Webseed objects and .torrent files will be advertised under /t/. Model weights themselves are not hosted on Pages.

See README.txt for the full layout, cache rules, and signature comments.
